About the Project

Smart Expense Tracker is a personal finance management web application developed using Java, Spring Boot, Spring Security, Thymeleaf, MySQL, Bootstrap, and Chart.js. It enables users to securely manage income and expenses, organize categories, search and filter expenses, track monthly savings, visualize category-wise expenses using pie charts, and analyze spending trends with an interactive monthly expense line chart. The application provides a modern, responsive dashboard for efficient financial management.

Core Modules
