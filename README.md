# 💰 Smart Expense Tracker

Smart Expense Tracker is a secure and user-friendly **Personal Finance Management Web Application** developed using **Java, Spring Boot, Spring Security, Thymeleaf, MySQL, Bootstrap, and Chart.js**.

The application helps users efficiently manage their daily income and expenses, organize transactions into categories, monitor monthly savings, and analyze spending patterns using interactive charts.

---

# 📌 Project Overview

Managing personal finances manually can be difficult and time-consuming. Smart Expense Tracker simplifies financial management by providing an intuitive platform where users can securely record income and expenses, categorize transactions, track monthly savings, and visualize financial data through interactive dashboards.

The project follows the **MVC Architecture** and implements secure authentication using **Spring Security**, ensuring that each user's financial information remains private and protected.

# 🏗️ Project Architecture

The application follows the **Model-View-Controller (MVC)** architecture with **Spring Security** for secure authentication and authorization.

- **Controller** – Handles HTTP requests, processes user actions, and returns the appropriate views.
- **Service** – Contains the business logic and coordinates application workflows.
- **Repository** – Performs database operations using Spring Data JPA.
- **Entity** – Represents the database tables and application models.
- **View** – Thymeleaf templates used to create a responsive user interface.
- **Spring Security** – Secures the application by providing user authentication, password encryption (BCrypt), session management, and access control for protected pages.
- **Security Configuration** – Configures authentication, authorization rules, login/logout functionality, and protects application endpoints using `SecurityConfig`.

# 🚀 Getting Started

### Prerequisites

- Java 17 or above
- MySQL
- Maven
- Eclipse / IntelliJ IDEA

### Installation

1. Clone the repository

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/SmartExpenseTracker.git
```

2. Configure the MySQL database.

3. Update database credentials in:

```
src/main/resources/application.properties
```

4. Run the Spring Boot application.

5. Open your browser and visit:

```
http://localhost:8080
```
